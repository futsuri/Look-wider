# Lookwider

[English](README.md) | [Русский](README.ru.md)

CTF-тулза для поиска данных, скрытых изменением размеров изображения.
Правит заголовки PNG, BMP и JPEG без перекодирования пикселей.

**Python 3.9+ · Без зависимостей при запуске**

## Установка

Из папки проекта, если установлен pipx:

```bash
pipx install .
```

Или запуск без установки:

```bash
python3 lookwider.py --help
```

## Использование

```bash
# Проверить заголовок и оценить полную высоту
lookwider inspect task.png

# Автоматически восстановить высоту PNG/BMP
lookwider recover task.png -o revealed.png

# Задать высоту и/или ширину вручную
lookwider set task.jpg --height 1024 -o revealed.jpg
lookwider set task.png --width 512 --height 1024 -o revealed.png

# Перебрать высоты: НАЧАЛО:КОНЕЦ:ШАГ (конец включительно)
lookwider sweep task.jpg --heights 600:1200:100 -d variants

# Исправить CRC IHDR в PNG без изменения размеров
lookwider set bad-crc.png -o fixed.png
```

При запуске без установки замените `lookwider` на `python3 lookwider.py`.
`inspect --json` выводит JSON. `--force` перезаписывает существующий результат;
исходник всегда защищён. `--max-mib` задаёт лимит чтения и распаковки
(по умолчанию 256 MiB на каждую операцию).

## Пример

В заголовке JPEG указано **512×516** пикселей. Увеличиваем высоту — открывается QR-код:

```bash
lookwider set docs/images/bigdawg-before.jpg --height 1024 -o revealed.jpg
```

| До: 512×516 | После: 512×1024 |
| --- | --- |
| <img src="docs/images/bigdawg-before.jpg" width="256" alt="Исходное изображение: QR-код скрыт за нижней границей"> | <img src="docs/images/bigdawg-after.png" width="256" alt="После восстановления: под фотографией виден QR-код"> |

Меняются только два байта высоты в SOF; размер JPEG остаётся **182 090 байт**.
Справа показано PNG-превью результата.

## Поддержка

| Формат | Автовысота | Ручные размеры |
| --- | --- | --- |
| PNG без interlace | Да, по строкам IDAT | Да, с исправлением CRC IHDR |
| PNG Adam7 | Нет | Да |
| BMP без сжатия / с битовыми масками | Кандидат по объёму пиксельных данных | Да |
| JPEG, включая progressive | Нет | Да, либо перебор через `sweep` |

Редактирование APNG и сжатых BMP не поддерживается. Хвост BMP может выглядеть
как дополнительные строки — проверьте результат визуально. Слишком большая
высота JPEG может дать артефакты. Восстановление возможно, только если скрытые
данные остались в файле.
